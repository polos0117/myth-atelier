# 그림 올리기

무기 이름과 그림이 오면 이 순서로 간다. 규칙의 원본은 `IMAGE_RULES.md`, 손은 `tools/upload-art.py` 가 한다.

## 1. 받은 것을 읽는다

- **카드** — `data/card.json` 의 `name` 정본으로 맞춘다. 오타가 흔하다(아른그레이프 → 야른그레이프). 스크립트가 비슷한 이름을 알려 준다. 정본으로 올리고 답할 때 한 줄 짚는다.
- **화풍** — "2.5d / 2.5D / 키아트" 는 `game_keyart`. 아무 말 없으면 `game_keyart`(기준 화풍). 다른 화풍은 `data/style.json` 의 key 로.
- **칸** — 그림은 보통 **기본 → 각성 → 저주 → 일상1 → 일상2…** 차례로 온다. 눈으로 확인한다:
  기본은 무기 재질이 옷·장갑에 옮겨 간 정면 전신, 각성은 같은 구도에서 빛이 켜진 것, 저주는 같은 구도에서
  심홍·검붉게 오염된 것, 일상컷은 다른 장소·다른 옷(도시·운동장·실내). 다섯 장이면 일상이 둘이다.
  extra 는 사용자가 "extra" 라고 말할 때만. 뒷모습이어도 춤·운동 같은 평상시 장면이면 일상컷이다(가다 때 바로잡힘).
- **스킨** — "티르핑 서리 스킨"처럼 오면 칸은 `skin_<열쇠>`, 셋이 오면 기본·각성·저주 차례로 `skin_<열쇠>` · `skin_<열쇠>_awaken` · `skin_<열쇠>_cursed`. 열쇠가 `data/card.json` 의 그 카드 `skins` 에 없으면
  먼저 적어서 코드 저장소에 올린 뒤에 그림을 올린다(등록기가 코드 저장소의 card.json 을 본다). 구도 대조 값이 낮아도
  옷이 통째로 바뀌어서일 수 있다 — 눈으로 같은 자세인지 본다.
- 그림 파일 경로는 메시지 끝에 붙어 온다(`/root/.claude/uploads/…/xxxx-image.png`). 표시 순서 그대로다.

## 2. 스크립트를 돌린다

```bash
cd /home/user/myth-atelier   # 저장소 위치가 다르면 거기서
python3 tools/upload-art.py <카드> --style game_keyart \
  base=<경로> awaken=<경로> cursed=<경로> casual1=<경로> \
  --trailer "Co-Authored-By: …" --trailer "Claude-Session: …"
```

- `--trailer` 에는 이 세션이 커밋에 붙이라고 받은 줄을 그대로 넣는다. 모델 이름은 커밋 메시지 본문엔 안 쓴다.
- 확신이 안 서면 먼저 `--dry` 로 바꾸기·대조만 보고, 맞으면 다시 돌린다.
- 그림 저장소는 옆 폴더 `../myth-atelier-img` 다. 없으면 `--img-repo` 로 준다.
- 카드 하나에 커밋 하나. 두 카드가 한 메시지에 오면 두 번 돌린다.

## 3. 수치를 읽는다

- **구도 일치**(각성·저주 대 기본): 0.6 이상이면 같은 원본. 0.3~0.6 은 그림을 열어 눈으로 본다.
  0.3 아래면 다른 구도 — 올리지 말고 사용자에게 어느 장이 어느 칸인지 묻는다.
- **명암**: 게임 키아트는 48~67 이 보통. 벗어났다고 화풍이 틀린 건 아니다 — 금·흰옷·밝은 하늘이면 낮게 나온다.
  선화·셰이딩이 키아트인지 눈으로 보고, 파스텔·수채처럼 결이 다르면 사용자에게 말한다(전에 미스틸테인이 그랬다).
- 카드의 `look` 이 같이 찍힌다. 그림에 그 재질·문양이 있는지 한 줄로 짚어 주면 사용자가 좋아한다.
- **무기가 안 보이는 게 맞다.** 인물이 곧 무기다(`IMAGE_RULES.md` "무기를 들지 않는다"). 무기가 없다고 짚지 않는다.
  오히려 손에 든 무기·떨어진 무기가 생겼으면 그게 흠이다.
- **손을 먼저 본다.** 손가락 수(다섯), 마디가 녹아 붙거나 휘었는지, 손이 물건·옷과 섞였는지. 수치로는 안 잡히니 눈으로 장마다.
  이상하면 올리기 전에 어느 장·어느 손인지 짚어 준다(`PROMPT_IMAGE_WORKFLOW.md` 기준컷 관문 "손은 손").
  기본이 틀리면 각성·저주도 같은 원본이라 셋이 같이 틀린다 — 그때는 셋을 다시 뽑자고 말한다.

## 4. 답한다

짧게, 평어로. 올라간 파일 수, 구도 일치·명암, `look` 이랑 맞는 점 한둘, 저주 문구(`curse.text`)랑 결이 맞는지,
그리고 스크립트가 찍은 커버리지(`카드 n/135 — 북유럽 · 그리스 · 한국 · 중국 · 일본 · 인도 · 이집트 · 서아시아 · 켈트`). 표·굵은 글씨는 아낀다.

## 안 되는 경우

- **자동 등록이 3분 넘게 안 됨** — 코드 저장소 Actions 의 "그림 등록" 을 수동 실행한다(`workflow_dispatch`, 필요하면 `prune: "true"`).
- **커밋 서명 503** — 스크립트가 세 번 다시 한다. 그래도 안 되면 잠깐 뒤에 다시.
- **화풍을 옮기고 싶을 때** — 그림 저장소에서 `git mv` 로 이름을 바꾸고 `img/thumb/` 의 옛 썸네일을 지운 뒤 푸시, 그리고 "그림 등록" 을 `prune: "true"` 로 돌린다.
- **같은 카드를 다시 뽑았을 때** — 같은 칸 이름으로 덮어쓰면 된다. 썸네일은 바뀐 파일만 다시 만든다.

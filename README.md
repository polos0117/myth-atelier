# myth-atelier

신화 속 무기를 사람으로 그린 카드로 하는 오토 배틀러. 북유럽·그리스·한국·중국·일본·인도·이집트·켈트, 권마다 열다섯(백스무 자루).

- `index.html` 공방 — 결 고르기, 패치 기록
- `dex.html` 도감 — 값·체력·공격·기술·원래 주인, 그림
- `auto.html` 오토 배틀러 — 상점에서 사서 앞줄·뒷줄에 놓으면 싸움은 자동
- `prompt.html` 그림 프롬프트 — 무기·화풍·출력을 고르면 영어 문장과 파일 이름

빌드 없음. 정적 파일이라 GitHub Pages 에 그대로 올린다. 그림은 `myth-atelier-img` 저장소에 따로 둔다.

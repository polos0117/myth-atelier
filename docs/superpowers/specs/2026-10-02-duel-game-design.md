# 신기 결투 — 설계

> 2026-10-02 · claude. 신화 무기 공방의 다섯째 놀이. 궨트(위쳐 3)식 1 대 1 카드 대결.
> 구현 계획은 이 문서를 승인한 뒤 따로 쓴다.

## 한 문장

> 덱 25장으로 손패 10장을 들고, 세 줄에 카드를 내려 힘의 합으로 세 라운드 중 둘을 따내는
> AI 상대 카드 대결. 열한 신화권의 주인을 이기며 각성판·저주판·날씨판까지 카드를 모은다.

## 왜 만드나

- 기존 넷(오토 배틀·드래프트·던전·박물관)과 겹치지 않는 놀이를 하나 더 둔다.
  체력 싸움이 없고, 카드를 **언제 내고 언제 버티느냐**(패스)가 전부다.
- 그림을 많이 보여 준다. 한 판에 카드 30장 넘게 판에 깔리고, 카드를 누르면 큰 그림이 뜨고,
  얻은 카드는 그림을 크게 띄워 공개한다. 각성판·저주판·날씨판이 별개 카드라 그림 4종(기본·각성·저주·일상컷)이 다 쓰인다.
- 폴드 덮개 화면(344×882)이 첫 화면이다. 모든 판단은 거기서 한 손으로 끝난다.

## 정해진 것 (대화에서)

| 갈림길 | 결정 |
|---|---|
| 공방 | 신화 무기 (myth-atelier) |
| 뼈대 | 궨트식 — 세 줄, 힘 합계, 세 라운드 중 둘, 패스 |
| 진행 | 시작 덱으로 출발해 이기면 카드를 얻는다 |
| 상대 | 열한 신화권의 주인(무기의 `wielder`)이 자기 권 덱을 든다 |
| 각성·저주 그림 | 같은 무기의 각성판·저주판을 별개 카드로 |
| 날씨 | 일상컷이 있는 카드의 날씨판(넷째 변형). 그 줄 양쪽 비영웅을 1로 |
| 통계 | 전적·주인·난이도·주 권별 승률에 카드별 승률까지 |
| 덱 | 주 신화권 하나 15장 이상 + 자유 10장 이하. 주 권의 진영 능력을 한 판에 한 번 |
| 수치 | 지금 자료에서 공식으로 파생하고, 안 맞는 카드만 `data/duel.json` 에서 덮어쓴다 |
| 이름 | 신기 결투. 머리 메뉴 "결투". 파일은 `duel` |

## 1. 한 판의 규칙

1. 덱 25장을 섞어 손패 10장을 뽑는다. 2장까지 덱 맨 위와 바꿀 수 있다(멀리건). 라운드 사이에 더 뽑지 않는다 —
   10장으로 세 라운드를 나눠 써야 한다. (진영 능력 "기"만 예외로 2장 뽑는다.)
2. 판은 양쪽에 근접·중거리·원거리 세 줄. 카드는 자기 줄에만 놓인다.
3. 선공은 동전 던지기(시드 난수). 라운드가 바뀌면 지난 라운드에 진 쪽이 선공. 동점이면 바꿔 가며.
   **1라운드의 선공은 합에 8(카드 한 장 값)을 미리 받는다** — 후공이 늘 교환의 마지막에 답하는 이점을 상쇄한다(구현 중 균형 보고에서 더했다:
   보너스 0 이면 선공 승률 36%, 8 이면 48%). 궨트 본편의 '전술 우위' 카드와 같은 장치.
4. 턴마다 셋 중 하나 — 카드 1장 내기(유닛은 자기 줄에, 날씨판은 자기 줄의 날씨로) · 진영 능력 쓰기(한 판에 한 번, 턴을 쓴다) · 패스.
   패스하면 그 라운드에는 더 못 낸다. 손패가 비면 자동 패스.
5. 둘 다 패스하면 라운드가 끝난다. 양쪽 세 줄의 힘 합을 견줘 큰 쪽이 이긴다.
   **동점이면 양쪽 다 진 것으로 센다.**
6. 목숨은 둘. 라운드에 지면 하나 잃는다. 먼저 둘 다 잃는 쪽이 진다. 같은 라운드에 둘 다 잃으면 무승부.
   최대 세 라운드.
7. 라운드가 끝나면 판 위 카드는 묘지로 간다(보호막·강화·피해는 사라진다). 날씨도 걷힌다.

## 2. 카드 파생

정본은 `data/card.json` 하나다. 결투용 수치는 `lib/duel.js` 의 `derive(data)` 가 만든다.
`data/duel.json` 의 `overrides` 는 카드 이름 → {power, ability, n} 으로 공식의 결과를 덮어쓴다(처음엔 비어 있어도 된다).

| 궨트 요소 | 어디서 | 규칙 |
|---|---|---|
| 줄 | `range` | melee → 근접 `melee`, reach → 중거리 `reach`, ranged → 원거리 `ranged` |
| 힘 | `atk` | `round(atk / 8)` → 4~13. 1금 평균 5, 5금 평균 12 |
| 영웅 | `cost` | 5금 카드 33장. 피해·파괴·봉인·강화·보호막·결속 어느 것도 받지 않는다. 자기 능력은 쓴다 |
| 능력 | `skill` → `skill.json` 의 `effect` | 아래 §3 |
| 그림 | `img.json` | 기본 `f`, 각성 `awaken.f`, 저주 `cursed.f`, 날씨 `casual.f[0]` (화풍은 `IMG.dressOf` 가 고르는 그대로) |

### 변형 카드

- **각성판** — 각성 그림이 있는 카드만(151장). 힘 +3. 능력·줄은 같다. 카드 id `이름@awaken`.
- **저주판** — 저주 그림이 있는 카드만(151장). 힘 +5. 대신 **상대가 카드를 낼 때마다 −1**(바닥 1),
  강화·보호막·결속을 받지 않는다. 늦게 낼수록 좋은 카드. 카드 id `이름@cursed`.
- 영웅(5금)의 변형판도 영웅이다(저주판 영웅은 피해는 안 받지만 자기 출혈은 받는다).
- **날씨판** — 일상컷이 있는 카드만(146장). 그림은 첫 일상컷. 유닛이 아니라 힘이 없다(0). 카드 id `이름@weather`.
  내면 **그 카드의 줄**에 날씨가 깔린다 — 근접은 서리, 중거리는 안개, 원거리는 비. 이름은 줄로 정해지고 낱말 표에 있다.
  날씨가 깔린 줄은 **양쪽** 비영웅 카드를 합산 때 **1** 로 센다(결속·강화도 무시). 영웅은 그대로. 카드의 힘 자체는 안 건드리므로
  걷히면 원래대로다. 같은 줄 날씨판을 또 내면 걷힌다(맑음). 라운드가 끝나면 걷힌다.
  능력이 아니라 봉인·호국·아스트라와 무관하고, 피해가 아니라 눈에는 눈도 세지 않는다. 낸 날씨판은 묘지로 간다(힘 0 이라 발할라·영생이 고르지 않는다).
- 그림이 새로 올라오면 `img.json` 이 바뀌고, 변형 카드도 그때 생긴다. 따로 등록하지 않는다.

### 결속

같은 **주인**(`wielder`)의 무기가 같은 줄에 둘 이상이면 각각 **기본 힘만큼 더한다**(두 배).
합산 때마다 다시 센다 — 하나가 파괴되면 결속도 풀린다. 영웅·저주판은 받지 않는다.
실제로 가능한 주인은 여덟(토르·아서·비슈누·헤라클레스·세종·나타·마르두크·르노)이라 희귀한 조합이다.

## 3. 능력 아홉

카드를 낼 때 한 번 터진다. 수치 `n` 은 기술의 `mult` 에서 — `n = clamp(round(mult), 1, 3)`, `mult` 가 없으면 2.
난사만 `n = min(targets, 3)`.

| 열쇠 | 이름 | 효과 | 원래 effect |
|---|---|---|---|
| `strike` | 타격 n | 상대 가장 센 비영웅 −n | strike, pierce |
| `sweep` | 휩쓸기 | 상대 **같은 줄** 비영웅 전부 −1 | sweep |
| `volley` | 난사 n | 상대 비영웅 무작위 n장 −1 | volley |
| `execute` | 처형 | 상대 가장 약한 비영웅이 힘 5 이하면 파괴, 아니면 −2 | execute |
| `seal` | 봉인 | 상대가 다음에 내는 카드의 능력이 안 터진다 | stun |
| `mend` | 강화 n | 내 같은 줄 가장 약한 비영웅(자신 포함) +n | heal, buff, haste |
| `rally` | 결집 | 내 같은 줄 나머지 비영웅 전부 +1 | rally |
| `shield` | 보호막 | 자신과 같은 줄 양옆 카드: 다음 피해 1회 무효 | shield, bulwark |
| `drain` | 흡혈 n | 상대 가장 센 비영웅 −n, 자신 +n | drain |

공통 규칙:
- 피해는 현재 힘을 깎는다. 바닥은 1 — 파괴는 처형·일섬만 한다.
- "가장 센/약한" 이 같으면 먼저 놓인 카드. 대상이 없으면 그냥 넘어간다.
- 보호막은 피해 한 번을 통째로 막고 사라진다. 파괴도 막는다.
- 봉인은 상대가 다음에 내는 **비영웅** 카드 한 장에 걸린다. 영웅을 내면 봉인은 소모되지 않고 남는다. 진영 능력은 봉인에 안 걸린다.
  라운드가 끝나면 봉인도 풀린다.
- 능력이 쓰는 난수(난사)는 판의 시드 난수.

## 4. 진영 능력 열하나

주 신화권의 능력. 한 판에 한 번, 턴을 써서 쓴다. 대상은 늘 규칙으로 정해져 고르는 조작이 없다.
이름·설명은 `data/duel.json` 의 `factions` 에 둔다(시너지 표의 이름을 그대로 쓴다).

| 권 | 이름 | 효과 |
|---|---|---|
| 북유럽 | 발할라 | 내 묘지에서 가장 센 카드 1장을 손으로 되돌린다 |
| 그리스 | 신의 가호 | 내 판의 가장 센 비영웅에 기본 힘만큼 더한다(두 배) |
| 한국 | 호국 | 이 라운드 동안 내 카드는 피해·파괴를 받지 않는다 |
| 중국 | 기 | 덱에서 2장 뽑는다 |
| 일본 | 일섬 | 상대 가장 센 비영웅을 파괴한다 |
| 인도 | 아스트라 | 다음에 내는 카드의 능력 수치가 두 배(n×2 · 휩쓸기·난사·결집은 ±2) |
| 이집트 | 영생 | 내 묘지에서 가장 센 카드 1장을 바로 자기 줄에 놓는다(능력은 안 터진다) |
| 서아시아 | 눈에는 눈 | 이 라운드에 내 카드가 받은 피해 합만큼 상대 가장 센 비영웅에서 깎는다 |
| 켈트 | 투혼 | 내 합이 상대보다 낮으면 내 모든 비영웅 +2 |
| 아메리카 | 비취의 숨 | 상대 가장 센 비영웅 −3, 내 가장 약한 비영웅 +3 |
| 기사 전설 | 롱스보의 맹세 | 내 묘지의 카드 수만큼(최대 5) 내 가장 센 비영웅에 더한다 |

## 5. 덱 규칙

- 정확히 25장. 주 신화권 15장 이상. 영웅(5금 기본판·변형판 합쳐) 4장 이하. 날씨판 3장 이하. 같은 id 는 1장.
  기본판·각성판·저주판·날씨판은 다른 id 라 함께 넣을 수 있다. 날씨판도 자기 권으로 센다.
- 주 신화권은 덱 짜기에서 바꾼다. 바꾸면 15장 규칙을 다시 본다.
- 규칙에 안 맞으면 출전을 못 한다. 화면이 무엇이 모자란지 바로 보인다.

## 6. 진행

- **처음**: 주 신화권을 고른다. 그 권 기본판 17장 + **그 권 날씨판 1장** + 다른 권 비영웅 기본판 7장(시드 무작위)이 컬렉션이자 시작 덱(첫 판부터 날씨를 써 본다 — 2026-10-02 고침).
- **상대**: 열한 주인. `data/duel.json` 의 `bosses` — 권 · 주인 이름(`wielder` 와 같은 글자) · 초상 카드 · 이웃 권.

  | 권 | 주인 | 초상 | 이웃 권 |
  |---|---|---|---|
  | 북유럽 | 토르 | 묠니르 | 켈트 |
  | 그리스 | 아테나 | 아이기스 | 이집트 |
  | 한국 | 이순신 | 거북선 | 중국 |
  | 중국 | 손오공 | 여의봉 | 한국 |
  | 일본 | 스사노오 | 천총운검 | 중국 |
  | 인도 | 비슈누 | 수다르샤나 | 서아시아 |

- **난이도** 신참·숙련·에이스(기존 놀이와 같은 이름). 주인 덱은 자기 권 17장 + 이웃 권 8장.
  신참은 이웃 8장을 무작위로, 숙련은 힘 순으로 8장에 자기 권 각성판 3장을 섞고, 에이스는 거기에 저주판 2장과 날씨판 2장을 더 섞는다
  (섞는다 = 그 수만큼 기본판을 변형판으로 바꾼다. 25장은 그대로). 주인 덱은 컬렉션 규칙을 안 따른다 — 상대라서.
- **보상 — 뒤집기**(2026-10-02 고침): 이기면 **뒷장 5장**이 깔리고 그 난이도 **첫 승리는 3장, 재대결은 1장**을 골라 뒤집는다.
  뒷장은 그 카드 권의 깃발이라 권만 보인다 — 운이다. 안 뒤집은 카드는 고르기가 끝나면 흐리게 뒤집혀 "놓친 카드" 로 보이고,
  안 뒤집고 떠나면 남은 몫은 자동으로 들어온다. 5장은 판이 끝날 때 시드로 정해 저장한다(새로고침해도 같다).
  5장의 종류 비율은 난이도가 정한다 — 신참 기본 65 · 각성 20 · 저주 10 · 날씨 5 / 숙련 35 · 30 · 20 · 15 / 에이스 15 · 25 · 25 · 35(%).
  그 종류 안에서는 값(1~5금)에 가중치 — 신참 고르게, 숙련 값만큼, 에이스 값의 제곱만큼 → 에이스일수록 영웅이 자주 깔린다.
  늘 아직 없는 카드만, 그 주인의 권에서 먼저, 모자라면 다른 권에서, 그래도 없으면 다른 종류. 5장 안에 같은 카드 없음. 가진 게 많아 5장이 안 되면 있는 만큼.
- **금과 상점**(2026-10-02): 판이 끝나면 금 — 이기면 신참 10 · 숙련 20 · 에이스 35, 지거나 비기면 참가비 3. 로비의 상점에는 **뒷장 6장**이
  깔리고 **값표만** 보인다(기본판 15~30 값 따라 · 각성판·저주판 40~60 · 날씨판 45 · 영웅 +20) — 비쌀수록 좋은 카드란 걸 알고 산다. 사면 그 자리에서 뒤집힌다.
  새로 깔 때 15% 는 **희귀 자리**(금빛 테두리 — 변형판 가운데 값 4~5금). 판을 하나 끝낼 때마다 한 칸이 돈다(산 자리부터, 아니면 가장 오래된 맨 앞).
  10금에 전부 새로 깐다. 아직 없는 카드만, 진열 안에 같은 카드 없음. 전부 가지면 빈 진열. `profile.gold` · `profile.shop = {rngState, stock:[{id, price, rare, bought}|null]}`.
  패배는 보상 없음. 무승부도 없음.
- **정복**: 열하나를 모두 한 번씩(어느 난이도든) 이기면 로비에 "정복" 표시. 그뿐이다.
- 컬렉션 상한은 기본 187 + 각성 151 + 저주 151 + 날씨 146 = 635. 그림이 늘면 상한도 는다.

## 6-1. 통계

`profile.stats` 에 쌓고 로비의 "전적" 에서 본다. 판이 끝날 때(승·패·무) 한 번 더한다.

```
stats: {games, win, lose, draw, streak, bestStreak, bestRound, rounds,
        byBoss:{권:{games,win}}, byLevel:{난이도:{games,win}}, byMain:{권:{games,win}},
        cards:{id:{played, won}}, factions:{권:n}}
```

- `bestRound` 는 한 라운드에서 내 합의 최고. `rounds` 는 치른 라운드 수 합(평균 라운드 = rounds/games).
- `cards[id].played` 는 그 카드를 **낸 판** 의 수(한 판에 여러 번 세지 않는다), `won` 은 그 가운데 이긴 판. 승률 = won/played.
- `factions[권]` 은 진영 능력을 쓴 횟수.
- 화면: 전적 줄(판·승·패·무·연승/최고) → 주인별·난이도별·주 권별 표(승/판) → 최고 합·평균 라운드 → **카드별 승률** 그리드
  (낸 판 수 순, 썸네일·낸 판·승률, 5판 미만은 승률 대신 "—") → 진영 능력 사용 수.
- 승률 표의 분모가 0이면 "—". 옛 저장에 `stats` 가 없으면 빈 통계로 시작한다.

## 7. AI

- 시드 난수로 결정적. 같은 시드·같은 손이면 같은 판.
- 수 고르기: 낼 수 있는 카드마다 "냈을 때 (내 합 − 상대 합)의 변화" 를 센다(능력·날씨까지 적용해 본 뒤 되돌린다).
  진영 능력도 한 수로 같이 센다. 날씨판은 상대가 그 줄에 많이 깔았을수록 이득이 크게 나오므로 따로 셈하지 않아도 된다.
- 패스:
  - 앞서는데 상대가 패스했으면 패스.
  - 뒤지는데 손패 전부로도 못 뒤집으면 패스(라운드를 버리고 카드를 아낀다). 단 목숨이 하나 남았으면 끝까지 낸다.
  - 둘 다 아니면 가장 이득인 수.
- 난이도:
  - 신참 — 이득 순위에 무작위를 섞고(상위 셋 중 하나), 패스 판단은 "앞서는데 상대 패스" 만.
  - 숙련 — 위 그대로.
  - 에이스 — 1라운드에는 영웅·저주판·진영 능력을 아낀다(상대가 패스해 꼭 필요할 때만). 저주판은 손패가 셋 이하일 때 낸다.
    날씨판은 이득이 4 이상일 때만 낸다(자기 줄도 같이 죽는다).
- 사람 쪽 턴에도 같은 셈이 "추천 수" 로 보이지는 않는다(범위 밖).

### 엔진 API (`lib/duel.js`)

모든 함수는 자료 `data = {cards, skills, img, duel}` 를 첫 인자로 받고 안에서 `cardsOf(data)`(파생 결과를 `data` 에 붙여 둔 것)를 쓴다.
`play`·`pass`·`useFaction` 은 **`st.turn` 쪽**의 한 수다 — 화면은 내 차례에만 부르고, 검사는 상대 수도 이걸로 둔다. 정확한 꼴은 구현 계획의 Interfaces 가 정본이다.

```
derive(data) · cardsOf(data)                 → {cards:{id→card}, list:[id…]}   // 파생 + overrides
newProfile(data, mainMyth, seed) · upgradeProfile(profile) · collectionMax(data)
validateDeck(data, profile)                  → {ok, problems:[열쇠…], n, main, hero, weather}
toggleDeck(data, profile, id) · setMain(profile, myth)
bossOf(data, myth) · bossDeck(data, rng, myth, level)
newMatch(data, profile, bossMyth, level, seed) → st        // phase 'mulligan'
mulligan(st, handIndex)   confirm(data, st)                // 2장까지 · phase 'play', 선공 결정
legal(data, st, who)      play(data, st, cardId)   useFaction(data, st)   pass(data, st)
aiMove(data, st, level)   aiTurn(data, st, level)          // 상대 한 수. 화면이 0.6초마다 부른다
scores(data, st)                             → {me:{rows,total}, foe:{…}}
settle(data, profile, st)                    → {result, cards:[id…], first} | null   // 보상 + 통계, 한 번만(st.rewarded)
winsOf(profile, myth) · conquered(data, profile) · statsView(data, profile)
```

상태는 통째로 JSON — `{v, seed, rngState, boss, level, round, turn, first, passed, lives, weather, me, foe, seq, log, roundLog, phase, winner, played, mulligans, rewarded, outcome, last}`.
`weather` 는 `{melee, reach, ranged}` 불 셋(양쪽 공용). `played` 는 이 판에 내가 낸 카드 id 목록(통계용).
`me`/`foe` 는 `{hand[], deck[], rows:{melee[],reach[],ranged[]}, grave[], faction:{myth, used}, hurt, sealed, astra, guard}`.
판 위 카드는 `{id, base, cur, hero, cursed, shield, at}`. 합산은 `scores()` 가 날씨·결속까지 넣어 센다 — 날씨 줄의 비영웅은 1.

카드 id: `이름` · `이름@awaken` · `이름@cursed` · `이름@weather`.

### 자료 (`data/duel.json`)

```
{"note": "...", "overrides": {"<이름>": {"power": 9, "ability": "strike", "n": 2}},
 "factions": {"norse": {"name": "발할라", "text": "..."}, …},
 "bosses": [{"myth": "norse", "wielder": "토르", "portrait": "묠니르", "ally": "celtic"}, …]}
```

### 저장

`localStorage` 의 `myth_duel_v1` 하나 — `{v, profile:{main, owned[], deck[], beaten:{권:{신참:n,…}}, level, stats}, match: st|null}`.
진행 중인 판은 매 수마다 저장하고 다시 열면 잇는다. 판이 끝나면 `match` 를 비운다. 통계는 판이 끝날 때 `profile.stats` 에 더한다.

### 말

화면 말은 전부 `lib/words.js` 의 `duel.*`. 능력 이름·설명과 날씨 이름(서리·안개·비)도 거기(`duel.ability.strike` · `duel.weather.melee` …).
진영 능력 이름·설명과 주인 이름은 자료(`duel.json` · `card.wielder`)라 표가 아니다. `<title>` 은 다른 화면과 같이 `app.title`(신화 무기 공방)이다 —
`tests/words.cjs` 가 모든 화면의 `<title>` 을 `app.title` 과 견준다. 화면 제목 "신기 결투" 는 머리(`duel.title`)가 보여 준다.

## 11. 범위 밖

- 사람끼리 대전, 미끼·첩자 같은 추가 카드 종류, 맑음 전용 카드(같은 줄 날씨판이 그 몫), 카드 거래·분해, 덱 여러 벌, 추천 수, 리플레이.
- **줄의 각성·저주 모드**(날씨판이 줄 전체를 각성 → 저주 → 맑음으로 돌리고 그림이 한꺼번에 바뀌는 것) — 볼거리는 크지만 양쪽 +3은
  몰아넣은 쪽을 더 밀어 눈덩이가 굴고, 저주 줄의 출혈은 뒤지는 쪽이 손해라 읽기 어렵다. 균형 보고 뒤에 "내 줄만 각성 그림으로 바꾸는
  진영 전용 카드" 꼴로 다시 본다.
- 균형 보고가 문턱 안이면 수치는 손대지 않는다. 밖이면 `overrides` 와 공식 상수(힘 나누기 8, 변형 +3/+5, 날씨판 상한 3)만 만진다.

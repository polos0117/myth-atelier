# 신기 결투 — 설계

> 2026-10-02 · claude. 신화 무기 공방의 다섯째 놀이. 궨트(위쳐 3)식 1 대 1 카드 대결.
> 구현 계획은 이 문서를 승인한 뒤 따로 쓴다.

## 한 문장

> 덱 25장으로 손패 10장을 들고, 세 줄에 카드를 내려 힘의 합으로 세 라운드 중 둘을 따내는
> AI 상대 카드 대결. 열한 신화권의 주인을 이기며 각성판·저주판까지 카드를 모은다.

## 왜 만드나

- 기존 넷(오토 배틀·드래프트·던전·박물관)과 겹치지 않는 놀이를 하나 더 둔다.
  체력 싸움이 없고, 카드를 **언제 내고 언제 버티느냐**(패스)가 전부다.
- 그림을 많이 보여 준다. 한 판에 카드 30장 넘게 판에 깔리고, 카드를 누르면 큰 그림이 뜨고,
  얻은 카드는 그림을 크게 띄워 공개한다. 각성판·저주판이 별개 카드라 그림 3종이 다 쓰인다.
- 폴드 덮개 화면(344×882)이 첫 화면이다. 모든 판단은 거기서 한 손으로 끝난다.

## 정해진 것 (대화에서)

| 갈림길 | 결정 |
|---|---|
| 공방 | 신화 무기 (myth-atelier) |
| 뼈대 | 궨트식 — 세 줄, 힘 합계, 세 라운드 중 둘, 패스 |
| 진행 | 시작 덱으로 출발해 이기면 카드를 얻는다 |
| 상대 | 열한 신화권의 주인(무기의 `wielder`)이 자기 권 덱을 든다 |
| 각성·저주 그림 | 같은 무기의 각성판·저주판을 별개 카드로 |
| 덱 | 주 신화권 하나 15장 이상 + 자유 10장 이하. 주 권의 진영 능력을 한 판에 한 번 |
| 수치 | 지금 자료에서 공식으로 파생하고, 안 맞는 카드만 `data/duel.json` 에서 덮어쓴다 |
| 이름 | 신기 결투. 머리 메뉴 "결투". 파일은 `duel` |

## 1. 한 판의 규칙

1. 덱 25장을 섞어 손패 10장을 뽑는다. 2장까지 덱 맨 위와 바꿀 수 있다(멀리건). 라운드 사이에 더 뽑지 않는다 —
   10장으로 세 라운드를 나눠 써야 한다. (진영 능력 "기"만 예외로 2장 뽑는다.)
2. 판은 양쪽에 근접·중거리·원거리 세 줄. 카드는 자기 줄에만 놓인다.
3. 선공은 동전 던지기(시드 난수). 라운드가 바뀌면 지난 라운드에 진 쪽이 선공. 동점이면 바꿔 가며.
4. 턴마다 셋 중 하나 — 카드 1장 내기 · 진영 능력 쓰기(한 판에 한 번, 턴을 쓴다) · 패스.
   패스하면 그 라운드에는 더 못 낸다. 손패가 비면 자동 패스.
5. 둘 다 패스하면 라운드가 끝난다. 양쪽 세 줄의 힘 합을 견줘 큰 쪽이 이긴다.
   **동점이면 양쪽 다 진 것으로 센다.**
6. 목숨은 둘. 라운드에 지면 하나 잃는다. 먼저 둘 다 잃는 쪽이 진다. 같은 라운드에 둘 다 잃으면 무승부.
   최대 세 라운드.
7. 라운드가 끝나면 판 위 카드는 묘지로 간다(보호막·강화·피해는 사라진다).

## 2. 카드 파생

정본은 `data/card.json` 하나다. 결투용 수치는 `lib/duel.js` 의 `derive(data)` 가 만든다.
`data/duel.json` 의 `overrides` 는 카드 이름 → {power, ability, n} 으로 공식의 결과를 덮어쓴다(처음엔 비어 있어도 된다).

| 궨트 요소 | 어디서 | 규칙 |
|---|---|---|
| 줄 | `range` | melee → 근접 `melee`, reach → 중거리 `reach`, ranged → 원거리 `ranged` |
| 힘 | `atk` | `round(atk / 8)` → 4~13. 1금 평균 5, 5금 평균 12 |
| 영웅 | `cost` | 5금 카드 33장. 피해·파괴·봉인·강화·보호막·결속 어느 것도 받지 않는다. 자기 능력은 쓴다 |
| 능력 | `skill` → `skill.json` 의 `effect` | 아래 §3 |
| 그림 | `img.json` | 기본 `f`, 각성 `awaken.f`, 저주 `cursed.f` (화풍은 `IMG.dressOf` 가 고르는 그대로) |

### 변형 카드

- **각성판** — 각성 그림이 있는 카드만(151장). 힘 +3. 능력·줄은 같다. 카드 id `이름@awaken`.
- **저주판** — 저주 그림이 있는 카드만(151장). 힘 +5. 대신 **상대가 카드를 낼 때마다 −1**(바닥 1),
  강화·보호막·결속을 받지 않는다. 늦게 낼수록 좋은 카드. 카드 id `이름@cursed`.
- 영웅(5금)의 변형판도 영웅이다(저주판 영웅은 피해는 안 받지만 자기 출혈은 받는다).
- 그림이 새로 올라오면 `img.json` 이 바뀌고, 변형 카드도 그때 생긴다. 따로 등록하지 않는다.

### 결속

같은 **주인**(`wielder`)의 무기가 같은 줄에 둘 이상이면 각각 **기본 힘만큼 더한다**(두 배).
합산 때마다 다시 센다 — 하나가 파괴되면 결속도 풀린다. 영웅·저주판은 받지 않는다.
실제로 가능한 주인은 여덟(토르·아서·비슈누·헤라클레스·세종·나타·마르두크·르노)이라 희귀한 조합이다.

## 3. 능력 아홉

카드를 낼 때 한 번 터진다. 수치 `n` 은 기술의 `mult` 에서 — `n = clamp(round(mult), 1, 3)`, `mult` 가 없으면 2.
난사만 `n = min(targets, 3)`.

| 열쇠 | 이름 | 효과 | 원래 effect |
|---|---|---|---|
| `strike` | 타격 n | 상대 가장 센 비영웅 −n | strike, pierce |
| `sweep` | 휩쓸기 | 상대 **같은 줄** 비영웅 전부 −1 | sweep |
| `volley` | 난사 n | 상대 비영웅 무작위 n장 −1 | volley |
| `execute` | 처형 | 상대 가장 약한 비영웅이 힘 5 이하면 파괴, 아니면 −2 | execute |
| `seal` | 봉인 | 상대가 다음에 내는 카드의 능력이 안 터진다 | stun |
| `mend` | 강화 n | 내 같은 줄 가장 약한 비영웅(자신 포함) +n | heal, buff, haste |
| `rally` | 결집 | 내 같은 줄 나머지 비영웅 전부 +1 | rally |
| `shield` | 보호막 | 자신과 같은 줄 양옆 카드: 다음 피해 1회 무효 | shield, bulwark |
| `drain` | 흡혈 n | 상대 가장 센 비영웅 −n, 자신 +n | drain |

공통 규칙:
- 피해는 현재 힘을 깎는다. 바닥은 1 — 파괴는 처형·일섬만 한다.
- "가장 센/약한" 이 같으면 먼저 놓인 카드. 대상이 없으면 그냥 넘어간다.
- 보호막은 피해 한 번을 통째로 막고 사라진다. 파괴도 막는다.
- 봉인은 상대가 다음에 내는 **비영웅** 카드 한 장에 걸린다. 영웅을 내면 봉인은 소모되지 않고 남는다. 진영 능력은 봉인에 안 걸린다.
  라운드가 끝나면 봉인도 풀린다.
- 능력이 쓰는 난수(난사)는 판의 시드 난수.

## 4. 진영 능력 열하나

주 신화권의 능력. 한 판에 한 번, 턴을 써서 쓴다. 대상은 늘 규칙으로 정해져 고르는 조작이 없다.
이름·설명은 `data/duel.json` 의 `factions` 에 둔다(시너지 표의 이름을 그대로 쓴다).

| 권 | 이름 | 효과 |
|---|---|---|
| 북유럽 | 발할라 | 내 묘지에서 가장 센 카드 1장을 손으로 되돌린다 |
| 그리스 | 신의 가호 | 내 판의 가장 센 비영웅에 기본 힘만큼 더한다(두 배) |
| 한국 | 호국 | 이 라운드 동안 내 카드는 피해·파괴를 받지 않는다 |
| 중국 | 기 | 덱에서 2장 뽑는다 |
| 일본 | 일섬 | 상대 가장 센 비영웅을 파괴한다 |
| 인도 | 아스트라 | 다음에 내는 카드의 능력 수치가 두 배(n×2 · 휩쓸기·난사·결집은 ±2) |
| 이집트 | 영생 | 내 묘지에서 가장 센 카드 1장을 바로 자기 줄에 놓는다(능력은 안 터진다) |
| 서아시아 | 눈에는 눈 | 이 라운드에 내 카드가 받은 피해 합만큼 상대 가장 센 비영웅에서 깎는다 |
| 켈트 | 투혼 | 내 합이 상대보다 낮으면 내 모든 비영웅 +2 |
| 아메리카 | 비취의 숨 | 상대 가장 센 비영웅 −3, 내 가장 약한 비영웅 +3 |
| 기사 전설 | 롱스보의 맹세 | 내 묘지의 카드 수만큼(최대 5) 내 가장 센 비영웅에 더한다 |

## 5. 덱 규칙

- 정확히 25장. 주 신화권 15장 이상. 영웅(5금 기본판·변형판 합쳐) 4장 이하. 같은 id 는 1장.
  기본판·각성판·저주판은 다른 id 라 함께 넣을 수 있다.
- 주 신화권은 덱 짜기에서 바꾼다. 바꾸면 15장 규칙을 다시 본다.
- 규칙에 안 맞으면 출전을 못 한다. 화면이 무엇이 모자란지 바로 보인다.

## 6. 진행

- **처음**: 주 신화권을 고른다. 그 권 기본판 17장 + 다른 권 기본판 8장(시드 무작위)이 컬렉션이자 시작 덱.
- **상대**: 열한 주인. `data/duel.json` 의 `bosses` — 권 · 주인 이름(`wielder` 와 같은 글자) · 초상 카드 · 이웃 권.

  | 권 | 주인 | 초상 | 이웃 권 |
  |---|---|---|---|
  | 북유럽 | 토르 | 묠니르 | 켈트 |
  | 그리스 | 아테나 | 아이기스 | 이집트 |
  | 한국 | 이순신 | 거북선 | 중국 |
  | 중국 | 손오공 | 여의봉 | 한국 |
  | 일본 | 스사노오 | 천총운검 | 중국 |
  | 인도 | 비슈누 | 수다르샤나 | 서아시아 |
  | 이집트 | 라 | 라의 칼 | 그리스 |
  | 서아시아 | 마르두크 | 마르두크의 활 | 인도 |
  | 켈트 | 아서 | 엑스칼리버 | 기사 전설 |
  | 아메리카 | 우이칠로포치틀리 | 시우코아틀 | 이집트 |
  | 기사 전설 | 롤랑 | 뒤랑달 | 켈트 |

- **난이도** 신참·숙련·에이스(기존 놀이와 같은 이름). 주인 덱은 자기 권 17장 + 이웃 권 8장.
  신참은 이웃 8장을 무작위로, 숙련은 힘 순으로 8장에 자기 권 각성판 3장을 섞고, 에이스는 거기에 저주판 2장을 더 섞는다.
  (주인 덱은 컬렉션 규칙을 안 따른다 — 상대라서.)
- **보상**: 어느 주인이든 그 난이도에서 **첫 승리**에 그 권 카드 3장, **재대결 승리**에 1장.
  얻는 차례는 기본판 → 각성판 → 저주판 가운데 아직 없는 것을 시드 무작위로. 다 모은 권이면 다른 권에서.
  패배는 보상 없음. 무승부도 없음.
- **정복**: 열하나를 모두 한 번씩(어느 난이도든) 이기면 로비에 "정복" 표시. 그뿐이다.
- 컬렉션 상한은 기본 187 + 각성 151 + 저주 151 = 489. 그림이 늘면 상한도 는다.

## 7. AI

- 시드 난수로 결정적. 같은 시드·같은 손이면 같은 판.
- 수 고르기: 낼 수 있는 카드마다 "냈을 때 (내 합 − 상대 합)의 변화" 를 센다(능력까지 적용해 본 뒤 되돌린다).
  진영 능력도 한 수로 같이 센다.
- 패스:
  - 앞서는데 상대가 패스했으면 패스.
  - 뒤지는데 손패 전부로도 못 뒤집으면 패스(라운드를 버리고 카드를 아낀다). 단 목숨이 하나 남았으면 끝까지 낸다.
  - 둘 다 아니면 가장 이득인 수.
- 난이도:
  - 신참 — 이득 순위에 무작위를 섞고(상위 셋 중 하나), 패스 판단은 "앞서는데 상대 패스" 만.
  - 숙련 — 위 그대로.
  - 에이스 — 1라운드에는 영웅·저주판·진영 능력을 아낀다(상대가 패스해 꼭 필요할 때만). 저주판은 손패가 셋 이하일 때 낸다.
- 사람 쪽 턴에도 같은 셈이 "추천 수" 로 보이지는 않는다(범위 밖).

## 8. 화면 (`duel.html`)

껍데기는 다른 놀이와 같다 — `WorkspaceHeader` + `.collection-scroll` 한 자리만 구른다. 말은 전부 `W()`.

1. **로비** — 주 신화권과 덱 상태(25/25 · 규칙 충족), 컬렉션 n/489, "덱 짜기". 아래에 주인 열하나가 카드로:
   초상(그 권 5금 무기 그림) · 이름 · 권 · 이긴 횟수 · 난이도 고르기 · "도전". 정복이면 띠 하나.
2. **덱 짜기** — 위에 주 신화권 고르기와 규칙 줄(장 수 · 주 권 · 영웅). 아래에 컬렉션 2열 그리드(도감 칸과 같은 모양,
   각성판·저주판은 모서리 표시). 누르면 담기/빼기. 덱에 든 카드는 테두리. 안 가진 카드는 안 보인다.
3. **대결** — 위에서 아래로:
   - 상대 띠: 주인 초상 작게 · 손패 수 · 묘지 수 · 진영 능력 썼는지
   - 상대 세 줄 (원거리 → 중거리 → 근접) — 줄마다 합계, 카드는 작은 썸네일(44×66)과 힘 숫자
   - 가운데 막대: 내 합 vs 상대 합 · 라운드 · 목숨 · **패스** 단추 · 진영 능력 단추
   - 내 세 줄 (근접 → 중거리 → 원거리)
   - 손패 띠: 가로 스크롤, 카드 72×108 에 힘·줄 표시. 누르면 상세(큰 그림 · 힘 · 능력 글 · 전승 한 줄)와 "내기".
     내면 자기 줄로 간다(줄을 고르는 조작은 없다).
   - 상대 턴은 0.6초 간격으로 한 수씩 보인다. 피해·강화 숫자가 카드 위로 떠오르고, 파괴는 흐려지며 사라진다.
     라운드 끝은 가운데에 결과 한 줄. 움직임 줄이기면 전부 즉시.
   - 멀리건은 대결 첫 화면에서 손패 10장을 크게 펼치고 2장까지 눌러 바꾼다.
4. **결과** — 승·패·무, 라운드 셋의 합, 얻은 카드를 한 장씩 크게 공개(그림이 주인공). "로비로" · "다시".

머리 메뉴는 일곱이 된다. 덮개 화면(599px 이하)에서는 두 줄(4 + 3)로 접는다. `header-layout.cjs` 의 탭 목록에 7번을 더한다.

## 9. 구조와 파일

### 새 파일

| 파일 | 무엇 |
|---|---|
| `lib/duel.js` | 엔진. 파생·덱 규칙·판 진행·능력·진영 능력·AI·보상. `window.AtelierDuel` / `module.exports`. DOM 모름 |

| `tests/duel-screen.cjs` | 브라우저 흐름 검사(덮개 화면) |

### 손대는 파일

`lib/words.js`(`duel.*`, `nav.duel`) · `lib/workspace-ui.js`(메뉴 7개, 제목 표) · `lib/workspace.css`(덮개에서 메뉴 두 줄) ·
`tests/header-layout.cjs`·`theme-screen.cjs`(화면 목록, 탭 7번) · `tests/data.cjs`(effect 13종이 모두 능력에 대응되나,
`duel.json` 의 카드 이름이 실재하나) · `AGENTS.md`(검사 목록) · `docs/PATCH.md`.

### 엔진 API (`lib/duel.js`)

```
derive(data)                      → {cards:{id→card}, byName}   // 파생 + overrides
newProfile(data, mainMyth, seed)  → profile
validateDeck(profile, cards)      → {ok, problems:[열쇠…]}
newMatch(data, profile, boss, level, seed) → st        // phase 'mulligan'
mulligan(st, handIndex)           // 2장까지
confirm(st)                       // phase 'play', 선공 결정
play(st, cardId)   useFaction(st)   pass(st)           // 사람 쪽 한 수
aiTurn(st)                        // 상대 한 수. 화면이 0.6초마다 부른다
scores(st)                        → {me:{rows,total}, foe:{…}}
reward(profile, st, data)         → 새 카드 id[] (profile 을 고친다)
```

상태는 통째로 JSON — `{v, seed, rngState, boss, level, round, turn, first, passed, lives, me, foe, lock, log, phase, winner}`.
`me`/`foe` 는 `{hand[], deck[], rows:{melee[],reach[],ranged[]}, grave[], faction:{myth, used}, hurt}`.
판 위 카드는 `{id, base, cur, shield, cursed, at}`. 합산은 `scores()` 가 결속까지 넣어 센다.

카드 id: `이름` · `이름@awaken` · `이름@cursed`.

### 자료 (`data/duel.json`)

```
{"note": "...", "overrides": {"<이름>": {"power": 9, "ability": "strike", "n": 2}},
 "factions": {"norse": {"name": "발할라", "text": "..."}, …},
 "bosses": [{"myth": "norse", "wielder": "토르", "portrait": "묠니르", "ally": "celtic"}, …]}
```

### 저장

`localStorage` 의 `myth_duel_v1` 하나 — `{v, profile:{main, owned[], deck[], beaten:{권:{신참:n,…}}, level}, match: st|null}`.
진행 중인 판은 매 수마다 저장하고 다시 열면 잇는다. 판이 끝나면 `match` 를 비운다.

### 말

화면 말은 전부 `lib/words.js` 의 `duel.*`. 능력 이름·설명도 거기(`duel.ability.strike` …). 진영 능력 이름·설명과
주인 이름은 자료(`duel.json` · `card.wielder`)라 표가 아니다. `<title>` 은 `duel.title` 과 같아야 한다.

## 10. 검사

- `tests/duel-sim.cjs` — 화면 없이 `lib/duel.js` 만.
  - 파생: 모든 카드에 줄·힘(4~13)·능력이 있다. effect 13종이 모두 대응된다. 변형판은 그림이 있는 카드에만, 수가 `img.json` 과 같다. 영웅 33장.
  - 같은 시드는 같은 판. 멀리건 2장 상한. 선공 규칙. 패스 뒤에는 못 낸다. 둘 다 패스하면 라운드 끝. 동점은 둘 다 목숨을 잃는다.
  - 능력 아홉과 진영 능력 열하나를 하나씩 손으로 짠 판에서 본다(영웅 면역·보호막·봉인·저주 출혈·결속 포함).
  - 덱 규칙 넷. 보상 규칙(첫 승 3장·재대결 1장·없는 것부터). 주인 덱 난이도별 구성.
  - AI 는 늘 합법인 수만 둔다. 세 난이도.
  - `--quick` 이 아니면 AI끼리 300판(권 11 × 난이도, 시드 고정)을 굴려 보고를 찍는다 — 선공 승률 · 권별 승률 · 평균 라운드 수 · 평균 판 카드 수.
    선공 승률이 40~60% 를 벗어나거나 한 권의 승률이 25% 미만·75% 초과면 실패. 그 밖은 보고.
- `tests/duel-screen.cjs` — 덮개 화면. 로비 → 주 권 고르기 → 덱이 규칙을 채운다 → 덱 짜기에서 빼면 규칙 줄이 빨개지고 출전이 막힌다 →
  주인 도전 → 멀리건 → 카드 내기(손패가 줄고 줄에 선다) → 패스 → 라운드 결과 → 끝까지 → 결과와 보상(컬렉션이 는다) →
  새로고침하면 판이 이어진다. 가로 넘침 없음, 누르는 자리 44px.
- 기존 검사 갱신: `header-layout`(7번 탭·`duel.html`), `theme-screen`(`duel.html`), `data`(대응 표·자료 이름), `words`(자동), `patch`.

## 11. 범위 밖

- 사람끼리 대전, 날씨·미끼·첩자 같은 추가 카드 종류, 카드 거래·분해, 덱 여러 벌, 추천 수, 리플레이, 통계 화면.
- 일상컷은 이 놀이에서 쓰지 않는다(도감·신전이 쓴다).
- 균형 보고가 문턱 안이면 수치는 손대지 않는다. 밖이면 `overrides` 와 공식 상수(힘 나누기 8, 변형 +3/+5)만 만진다.
